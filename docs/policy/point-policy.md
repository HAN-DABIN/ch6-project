# Point Policy

포인트는 커피 주문의 유일한 결제 수단이다.
포인트 정책은 정확성과 데이터 일관성을 우선한다.

## 기본 규칙

- 사용자는 하나의 포인트 계좌를 가진다.
- 현재 잔액은 `points` 테이블을 기준으로 한다.
- 포인트 충전 금액은 1원 = 1P로 계산한다.
- 포인트 잔액은 음수가 될 수 없다.

## 충전 규칙

- 충전 금액은 0보다 커야 한다.
- 충전 성공 시 `points.balance`를 증가시킨다.
- 충전 성공 시 `point_histories`에 `CHARGE` 이력을 기록한다.

## 사용 규칙

- 포인트 사용 금액은 0보다 커야 한다.
- 사용 금액은 주문 메뉴의 가격과 동일해야 한다.
- 잔액이 부족하면 주문과 결제는 생성되지 않는다.
- 사용 성공 시 `points.balance`를 감소시킨다.
- 사용 성공 시 `point_histories`에 `USE` 이력을 기록한다.

## 동시성 규칙

- 같은 사용자의 포인트를 동시에 차감할 수 있으므로 동시성 제어가 필요하다.
- 포인트 차감은 정확성이 중요하므로 비관적 락을 우선 고려한다.
- 중복 차감이나 음수 잔액이 발생하면 안 된다.
