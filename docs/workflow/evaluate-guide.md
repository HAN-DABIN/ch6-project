# Evaluate Guide

Evaluate 단계는 구현 결과가 요구사항과 계획을 만족하는지 검증하는 단계다.

## 목적

- 테스트 또는 실행으로 구현 결과를 확인한다.
- 계획한 통과 기준을 만족하는지 판단한다.
- 실패 또는 미검증 상태를 사실대로 기록한다.

## 절차

1. 변경된 기능과 관련된 테스트를 확인한다.
2. 가능한 경우 `./gradlew test`를 실행한다.
3. 필요한 경우 `./gradlew compileJava`로 컴파일을 확인한다.
4. API 기능은 Postman 또는 curl로 응답을 확인한다.
5. 테스트 결과와 남은 리스크를 기록한다.
6. 실패하거나 실행하지 못한 검증은 이유와 다음 확인 방법을 남긴다.

## 통과 기준

- 컴파일이 성공한다.
- 관련 테스트가 성공한다.
- API 응답이 명세와 일치한다.
- 도메인 정책을 위반하지 않는다.

## 검증 기록 템플릿

```md
## Evaluate 기록

- 검증일: YYYY-MM-DD
- 실행한 명령:
- 결과:
- 실패한 경우 원인:
- 실행하지 못한 경우 이유:
- 남은 리스크:
- 다음 확인 사항:
```

## 금지 사항

- 테스트를 실행하지 않았는데 성공했다고 말하지 않는다.
- 실패 원인을 숨기지 않는다.
- 검증하지 않은 내용을 완료로 표시하지 않는다.
